Website Usability Evaluation

1. Website Name and URL

Name: NASA

URL: https://www.nasa.gov

2. Target Audience

This website is for students, teachers, space enthusiasts, researchers, and anyone interested in learning about space and science.

3. Site Organization

The website is organized with a top navigation menu including sections like Missions, News, Images & Videos, and About NASA. Each section links to more detailed pages in a clear hierarchy.

4. CRAP Design Principle Example

The site uses Contrast by having dark text on light backgrounds and light text on dark backgrounds, making it easy to read. It also uses Alignment because text and images are neatly lined up.

5. Accessibility Audit Score

The site has an approximate accessibility score of 90–95 according to tools like Lighthouse.

6. Site Effectiveness

The website is effective because users can easily find information about space missions, news, images, and videos without confusion.

7. Site Efficiency

The website is efficient because tasks like searching for information or navigating to specific topics can be done quickly using the menu and search bar.

8. Engagement

The website is engaging with interactive content, high-quality images, videos, and clear visuals related to space exploration.

9. Recommendation

One recommendation for improvement is to simplify pages that contain too much information at once to make them less overwhelming for new users.
