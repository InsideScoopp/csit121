Reflection from Lab 02

Creating my first webpages was a new experience for me. At first, remembering all the HTML tags felt overwhelming, but practicing step by step made it much easier. I now better understand how webpages are structured. Learning about semantic elements helped me organize my content better.

What I Learned

Reflection from Lab 03

In this lab, I learned how to separate content from design by using an external CSS file. It was interesting to see how adding styles like background colors, fonts, and spacing can completely change the appearance of a webpage. I also learned how ID and class selectors help target specific sections of a page. One question I still have is how large websites organize their CSS when there are many pages. Resources I used include MDN Web Docs, freeCodeCamp, and web.dev Learn CSS.
