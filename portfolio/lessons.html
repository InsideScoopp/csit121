Lessons Learned

This project helped me understand how websites are built using HTML and CSS. One challenge I had was making sure all my pages were connected correctly and making the design look consistent on every page. At first I had small mistakes in my code, but fixing them helped me learn more about web development.

I also learned that websites can look different depending on the browser or device being used. Testing my website on my phone and different browsers helped me fix spacing and layout problems. The mobile media query also helped make the website easier to use on smaller screens.

Overall, this course taught me how to use HTML, CSS, images, links, tables, and navigation to create a complete website. I learned how important it is to stay organized and test my work carefully before submitting it.
