Website Usability Evaluation

1. Website Name and URL

Name: NASA

URL: https://www.nasa.gov

2. Target Audience

This website is designed for a wide audience, including students, educators, space enthusiasts, and anyone curious about science and space exploration.

3. Site Organization

The site is organized with a clear top navigation menu that includes sections like Missions, News, Images & Videos, and About NASA. Each section links to more detailed pages, making the content easy to explore.

4. CRAP Design Principle Example

The website uses Contrast by pairing dark text with light backgrounds and vice versa, which makes the text easy to read. It also uses Alignment since text and images are arranged in a neat and orderly way.

5. Accessibility Audit Score

The accessibility score is approximately 90–95 according to tools like Lighthouse, indicating the site is mostly accessible to all users.

6. Site Effectiveness

The site is effective because it allows users to quickly find information on space missions, news, and images without confusion, supporting accurate completion of tasks.

7. Site Efficiency

The website is efficient since users can navigate easily using the top menu and search bar, which helps them accomplish tasks quickly.

8. Engagement

The site is engaging thanks to high-quality images, videos, and interactive content. It provides a pleasant experience while staying relevant to the topic of space exploration.

9. Recommendation

One suggestion for improvement is to simplify pages with a lot of information at once. Breaking content into smaller sections would make it less overwhelming for users.
